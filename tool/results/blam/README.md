# B_λ of the tag runs, and Lemma "runs"

B_λ counts the tag boundaries of the BWT whose two suffixes share more than λ characters. The lemma's bound is
ρ ≤ (r + σ + 2d)(λ + 1) + B_λ + 1.

## Zymo (homopolymer-compressed reference, per-species tags), 2026-11-04/05, 3ab8589

`index --tags --by-tag --no-rmq --tag-out /dev/null --tag-lcp 0,10,30,100,1000 --tmp DIR` (`zymo_run.sh`), with the
text, the BWT and the temporary files on the external USB drive, capped at 11 GB. The BWT is KATKA's `zy.bwt`,
copied from the laptop. The text was regenerated by `prep` and checked, byte for byte, against a second fresh
`prep` afterwards.

ρ = 448,723,822, r = 338,097,187, σ = 6, d = 7.

| λ | B_λ | bound | ρ / bound |
|---|---|---|---|
| 0 | 448,723,813 | 786,821,021 | 0.570 |
| 10 | 448,430,416 | 4,167,499,694 | 0.108 |
| 30 | 107,938,468 | 10,588,951,886 | 0.042 |
| 100 | 97,171,998 | 34,244,989,906 | 0.013 |
| 1000 | 65,409,566 | 338,500,713,774 | 0.0013 |

The bound holds at every λ, and it is tightest at λ = 0. Almost every tag boundary (448.4 M of 448.7 M) has suffixes
sharing more than 10 characters, but only 24% share more than 30.

Time and memory: 45,571 s (12.7 h), peak 10.77 GB.
- **RLBWT:** 1,972 s.
- **LF pass:** about 2.3 h.
- **φ pass:** until 27,264 s (7.6 h, CPU-bound), writing the boundary records and tag runs.
- **The five text passes** (one λ each):
  - 2,554, 2,642, 2,720 and 2,795 s for λ = 0, 10, 30, 100;
  - 5,357 s for λ = 1000.

  These were on the USB drive, the λ = 100 and 1000 passes alongside the SILVA uniform simulation and scoring.
- **Temporary files:** 16 GB on the external drive.

**Check of the tag runs:** the `zy.sp.tagruns` this run computed from the BWT is **byte-identical** to the index's,
which was converted from KATKA's laptop file (`results/zymo/`). So the converted file is confirmed in full, not only
on the 35 M rows of `check_tagruns`. The run count also equals the 448,723,822 of the laptop's log.
